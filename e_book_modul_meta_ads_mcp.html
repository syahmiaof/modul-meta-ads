Prakata & Cara Guna Ebook Ini

Modul ini ditulis khas untuk usahawan, pelajar, dan sesiapa sahaja yang tiada latar belakang pengaturcaraan (non-technical).

Banyak tutorial di internet terlalu teknikal dan mengelirukan — menggunakan istilah seperti endpoint, OAuth, payload, webhook tanpa menerangkan di mana letaknya butang sebenar di skrin.

Dalam modul ini, anda akan dipimpin langkah demi langkah (click-by-click):

  • Di mana nak klik tetikus anda di portal Meta.
  • Warna dan nama butang yang perlu ditekan.
  • Apa maksud setiap kod/ID yang anda jumpa.
  • Macam mana nak dapatkan "Kunci Digital" (Token) yang tidak luput.
  • Bagaimana AI Agent di Antigravity menggunakan MCP untuk membaca ads dan membina kempen secara autonomi.
  • Macam mana nak hubungkan semuanya tanpa risiko akaun disekat atau bajet terbakar.

2 Membina Facebook Page & Mencari "Page ID"

Langkah 2.1: Bina Facebook Page (Jika Belum Ada)

  1. Buka pelayar web dan layari https://www.facebook.com/pages/create.
  2. Pada panel sebelah kiri:
    • Page Name: Masukkan nama syarikat (Contoh: Demo SME Sdn Bhd).
    • Category: Pilih kategori yang sesuai.
    • Bio: Tulis 1-2 ayat ringkas mengenai bisnes anda.
  3. Tekan butang biru Create Page di bahagian bawah kiri.
  4. Muat naik gambar profil (Logo) dan gambar cover (Banner).
  5. Tekan butang "Save" / "Done".

Langkah 2.2: Kat Mana Nak Cari "Page ID"? Paling Penting!

Ramai orang tersilap masukkan nama Page, sedangkan sistem automasi hanya kenal Nombor ID.

  1. Masuk ke Facebook Page anda sebagai profil Page tersebut.
  2. Di menu sebelah kiri, klik tab "About" (Tentang).
  3. Skrol ke bawah dan klik tab "Page Transparency" (Ketelusan Halaman).
  4. Anda akan melihat satu kotak maklumat bertulis:
    Page ID: 1389752850879310
Tindakan Anda:

Salin nombor ini dan simpan dalam Notepad anda. Labelkan sebagai META_PAGE_ID.

3 Menyediakan Meta Business Suite & Akaun Iklan

3.1: Buka Meta Business Suite

  1. Buka business.facebook.com.
  2. Di penjuru atas kiri, pastikan nama Business Portfolio / Perniagaan anda dipilih.
  3. Di menu bar sisi sebelah kiri paling bawah, cari dan klik ikon gear bertulis "Settings" atau terus ke business.facebook.com/settings.

3.2: Dapatkan / Cipta "Ad Account ID"

Sistem AI memerlukan Ad Account ID untuk merangka kempen iklan.

  1. Di Business Settings, lihat menu kiri bawah "Accounts".
  2. Klik "Ad Accounts" (Akaun Iklan).
  3. Jika sudah ada: Lihat ID di sebelah nama. Format: act_123456789...
  4. Jika belum ada: Klik butang Add -> Create a new ad account.
    • Timezone: GMT+08:00 Asia/Kuala_Lumpur
    • Currency: MYR
Simpan nombor ini sebagai META_AD_ACCOUNT_ID. (Mesti ada awalan act_).

4 Daftar Meta Developer App (Laluan Rasmi API)

Untuk membolehkan kod bercakap dengan Meta, kita perlu daftarkan satu "Aplikasi Penghubung".

4.1: Portal Meta for Developers

  • Layari: developers.facebook.com
  • Log masuk akaun Facebook anda.
  • Klik "Get Started" jika pertama kali.
  • Pergi ke menu "My Apps".

4.2: Cipta Aplikasi Baharu

  • Klik butang Create App.
  • Use Case: Pilih Other -> Next.
  • App Type: Pilih Business -> Next.
  • App Name: Demo_SME_Automation (Jangan letak perkataan Meta/FB).
  • Pilih Business Account anda -> Create App.

Langkah 4.3: Di Mana Nak Ambil App ID & Secret?

  1. Di menu kiri (Dashboard App), klik App settings -> Basic.
  2. Salin App ID Simpan sebagai META_APP_ID
  3. Klik butang 'Show' pada kotak bertutup untuk paparkan App Secret.
  4. Salin kod tersebut Simpan sebagai META_APP_SECRET

AMARAN KESELAMATAN

App Secret ibarat nombor PIN kad ATM anda. Jangan sesekali kongsi kod ini di Facebook, WhatsApp awam, atau GitHub!

5 System User & Token Akses Kekal

THE HOLY GRAIL: Kenapa guna System User? Token biasa luput 1 jam/60 hari (automasi akan mati malam-malam!). Token System User adalah KEKAL (Never-Expiring).

5.1: Cipta System User

  • Buka Business Settings.
  • Menu Kiri: Users -> System Users.
  • Klik butang Add.
  • Nama: Jebat_Bot
  • Role: Pilih Admin (Wajib).
  • Klik Create.

5.2: Assign Assets PENTING

  • Klik nama Bot tadi, tekan Assign Assets.
  • Pages: Tanda Page anda -> Buka suis Full Control.
  • Ad Accounts: Tanda Akaun anda -> Buka suis Manage Campaigns.
  • Klik Save Changes.

5.3: Generate Token

  • Klik Generate New Token.
  • Select App: Pilih App Bab 4.
  • Expiration: Never.
  • Tick Permissions (Sangat Penting):
pages_show_list pages_read_engagement pages_manage_posts pages_manage_engagement ads_management ads_read leads_retrieval pages_manage_ads

SIMPAN token panjang (EAA...) sebagai META_SYSTEM_USER_TOKEN. Meta tak tunjuk lagi lepas ni!

6 Uji Token (Graph API)

Uji sama ada kunci sah dan berfungsi.

  1. Buka Graph API Explorer.
  2. Padam Access Token lama, tampal (paste) Token System User (EAA...) anda.
  3. Di bar URL (Kaedah GET), taip:
    me?fields=name,id
  4. Klik Submit.
Hasil (Status: 200 OK) 
{
  "name": "Demo_App",
  "id": "112233445566"
}

7 Dapatkan Instant Form ID

Untuk kempen Lead Generation.

  1. Di Business Suite, cari All Tools -> Instant Forms.
  2. Klik Create Form -> New Form.
  3. Isi nama (Borang_Pertanyaan).
  4. Tambah soalan: Contact Fields -> Phone Number.
  5. Letak URL Privacy Policy.
  6. Klik Create Form.

Salin Form ID dari senarai dan labelkan sebagai META_LEAD_FORM_ID.

Integrasi Antigravity & MCP (AI Agent)

(Ini bahagian paling moden dan berkuasa dalam buku ini! Bukan lagi bercakap pasal kod skrip manual, tapi bagaimana AI Agent berfikir dan bertindak sendiri).

9.1 Kenapa Guna MCP & AI Agent?

Cara Lama (Manual)

  • Kena upah programmer tulis Python ratusan baris.
  • Bila API berubah, skrip rosak, koding balik.
  • Manusia masih kena buka Ads Manager setiap hari.

Cara Baru (MCP + AI)

  • LLM (Otak): Menganalisis metrik & copywriting.
  • MCP (Tangan & Mata): Sambung terus ke Meta API.
  • Arahan dlm bahasa biasa: "Tolong baca kempen hari ni, kalau CTR teruk, tukar copywriting."

9.2 Empat Objektif & Jangkaan Hasil

🎯 1. Audit Masa Nyata (Real-Time)

AI panggil meta_get_insights. Jika CTR < 1%, AI amaran di WhatsApp & sedia ayat baru sbb audiens dah jemu (fatigue).

🎯 2. Draf Kempen Pintar

Anda suruh: "Buat kempen lead restoran". AI guna meta_create_campaign_draft, set bajet selamat, status PAUSED. Tiada sen terbakar.

🎯 3. Kawalan Bajet (Hard-Lock)

AI semak baki dengan meta_get_ad_account_details. Halang bajet lebih RM15 tanpa pengesahan manusia.

🎯 4. Diagnosis Ralat (Self-Healing)

Jika iklan ditolak (Ad Rejected), AI faham kod ralat, terjemah ke BM, dan baiki ayat janji berlebihan secara automatik.

10 Cara Selesaikan Masalah (Error)

Kod Ralat Mesej Lazim Sebab Utama Cara Selesai Segera
Error 190 Invalid OAuth access token Token salah salin, atau guna token sementara yg dah luput. Jana token baharu (System User). Pilih tempoh Never.
Error 200 / 100 Permissions error / Missing scope System User takde kebenaran utk fungsi tu. Semak Bab 5.3. Tick kebenaran ads_management dll.
Error 273 Cannot create ad for this page System User belum diberi aset Page/Ad Account. Masuk Business Settings -> System Users -> Assign Assets.
Error 1487843 Dev mode app restriction Meta App masih status In Development (tak boleh post awam). Guna muat naik published: false sebelum dipaut ke iklan.
Timeout Tool call failed / Server unavailable Pelayan MCP lokal belum hidup / port salah. Pastikan .env ada port yg betul & jalankan health-check MCP.
